# Paper Story Line

1. Geometry is intuitively useful for manipulation, but naive learned geometry can be harmful.
2. Phase 0 IsaacLab experiments reveal this failure mode and motivate stronger no-G controls.
3. Phase 1 CALVIN rebuilds the question in a standardized dual-camera manipulation setup.
4. We compare no-G, GT/explicit geometry, learned geometry, and stronger action decoders.
5. The goal is not to claim that G always wins, but to characterize when and how geometry should be injected.
